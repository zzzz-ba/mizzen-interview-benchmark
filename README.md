# Mizzen 访谈 Benchmark

[打开访谈案例审阅页](https://zzzz-ba.github.io/mizzen-interview-benchmark/) · [随机 30 场访谈](https://zzzz-ba.github.io/mizzen-interview-benchmark/random-interviews-30.html)

首页展示 2026 年 11 月 6 日暂停时的标注快照。默认查看定额采样，可切换到比例采样。访谈按全部消息、研究目标和历史大纲精确去重，同一访谈中的同一组目标主持发言只计一个案例。

| 采样方式 | 已完成的有效访谈 | 有效案例 | Good | Bad |
|---|---:|---:|---:|---:|
| 定额采样 | 1,233 | 15,736 | 11,213（71.26%） | 4,523（28.74%） |
| 比例采样 | 1,069 | 10,921 | 8,313（76.12%） | 2,608（23.88%） |

两种采样共有 334 份有效访谈和 4,147 个案例。合并后共有 1,968 份有效访谈、22,510 个不同案例。

页面内可按行业、维度、Good / Bad 和审核状态筛选，点开案例可核对被评片段、完整会话、历史大纲及审核历史。公开版将识别到的联系方式和收件信息遮盖在内置数据中。个人新写的审核意见存于当前浏览器，可导出 JSON 备份。

GitHub Pages 从本仓库 main 分支根目录的 index.html 发布。
